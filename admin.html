Plataforma

Con Seleccionar, haz clic en cualquier tramo de suelo o plataforma aérea para editar su tipo, movimiento, cinta o rebote.

Trampa

Usa la herramienta Trampa (7) para colocar pinchos, vapor, láser, aplastador o sierra donde quieras y cárgales cualquier imagen PNG.

Vida / Poder / Botón / Meta

Usa Vida/Poder/Meta (8) para colocar Vidas (+1 ♥), el Poder de Doble Salto (2X), Botones/Palancas para accionar plataformas o trampas, Checkpoints o el Ascensor Meta.

Objeto

Con la herramienta Objeto (9), haz clic donde quieras para colocar uno y asígnale cualquier imagen PNG.

Catálogo de objetos

Cada tipo se define una vez (imagen, tamaño, modo y caja de colisión) y se coloca en cualquier piso. Haz clic en uno para editarlo y colocarlo.

Márgenes de colisión (px)

Recortan la caja con la que choca el jugador, para no contar el borde transparente del PNG. La base siempre es la de la imagen.

Prueba

Flechas para correr · Espacio para saltar · C para ver las colisiones · Esc para volver al editor. Se prueba el estado actual, aunque no esté guardado.
